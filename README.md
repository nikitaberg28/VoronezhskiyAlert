## VoronezhskiyAlert

фабрик клиент-сайд мод (возможно на некоторых серверах чит, но по политике MineLand, CubeCraft, Mineblaze - можно. Перед установкой убедитесь в легитности на вашем сервере)

## основы
- H — меню настроек
- J — поставить флажок
(все бинды можно настроить в настройках клавиш в самом майне)
- обновлено под Minecraft 26.x (проверено на 26.2). Начиная с 26.1 Minecraft
  больше не обфусцирован и Fabric использует официальные маппинги Mojang
  вместо Yarn — из-за этого имена части классов в коде мода могли поменяться,
  см. `PORTING_NOTES.md` в корне репозитория со списком мест, которые стоит
  перепроверить через `genSources` в IDE перед сборкой.
Вы также можете скачать zip архив этого репозитория, скинуть ии и обновить самим, итоговый jar будет хранится в `build/libs/`
