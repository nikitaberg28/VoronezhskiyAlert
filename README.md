## VoronezhskiyAlert

фабрик клиент-сайд мод (возможно на некоторых серверах чит, но по политике MineLand, CubeCraft, Mineblaze - можно. Перед установкой убедитесь в легитности на вашем сервере)

## основы
- H — меню настроек
- J — поставить флажок
(все бинды можно настроить в настройках клавиш в самом майне)
- пока что только 1.21.11, в будущем обновлю.
Вы также можете скачать zip архив этого репозитория, скинуть ии и обновить самим, итоговый jar будет хранится в `build/libs/`
